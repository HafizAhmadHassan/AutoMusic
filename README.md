# AutoMusic
*Created: 2022-06-12*

A machine-learning project for **automatic music / melody generation**.

## Overview

Trains models on musical data to generate new melodies automatically. The repository is organised with a `data/` folder for training data and a `model/` folder for the model code.

## Repository Structure

```
├── data/          # Training data
└── model/         # Model implementation
```

## Features

- Train machine-learning models on music data
- Generate melodies

## Tech Stack

Python, deep learning, generative models.

## Status

Research / hobby project.
